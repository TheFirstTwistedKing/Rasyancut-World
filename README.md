# Rasyancut-World

금빛 인장이 새겨진 검은 산업 콘솔. 정적 파일만 있어서 `index.html`을 열면 동작한다.

## 화면

| 화면 | 주소 | 내용 |
|---|---|---|
| 메인 | `#/main` | 좌측 텍스트·아이콘 메뉴, 우측 상단 메인 메뉴 아이콘, 캐릭터 캐러셀 |
| 캐릭터 선택 | `#/select` | 세로 배너 카드 6장. 눌러서 선택 → 다시 누르거나 하단 버튼으로 입장 |
| 캐릭터 소개 | `#/char/1` ~ `#/char/6` | 이름·소개문·정보표, 이전/다음 이동 |
| 컨셉아트 | `#/gallery` | 15장, 작은 그림 2장 + 큰 그림 1장 반복, 스크롤, 크게 보기 |
| 공지 | `#/notice` | 패치 노트 (`Patch v-X.Y.Z`) |

화면이 바뀔 때마다 전환 연출이 재생되고, 본문은 글자 단위로 나타난다. 모바일(320px~)과 키보드 조작, 동작 줄이기 설정을 지원한다.

## 파일

- `index.html` — 뼈대
- `styles.css` — 스타일 (글꼴 2종, 8px 간격, 글자 크기 스케일)
- `app.js` — 화면·전환·라우터
- `data.js` — **내용 데이터** (아래 참고)
- `art.js` — 실제 그림이 없을 때 쓰는 임시 일러스트 생성기
- `motion.js` — 모션 레이어(입장 인트로·시차·금가루·라이트박스·공지 접기). **시간·강도·개수는 파일 맨 위 `MOTION` 객체에서 조절**하고, `intro.enabled = false` 로 인트로를 끈다

## 내용 바꾸기

`data.js` 한 파일만 고치면 된다.

- **캐릭터 그림**: `characters[].img`에 경로를 넣는다. 예: `img: 'img/char-01.webp'`
- **컨셉아트 그림**: `concept[].img`에 경로를 넣는다.
- **이름·소개문·정보표**: `characters[]`의 `name`, `en`, `short`, `intro`, `specs`
- **공지**: `notices`의 맨 앞에 새 항목을 추가한다. 이름은 `Patch v-X.Y.Z` (대규모 X, 중규모 Y, 소규모 Z).

`img`가 비어 있거나 파일이 없으면 `art.js`가 만든 임시 일러스트가 대신 나온다.
