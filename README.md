# Rasyancut-World

금색 × 검정 기반의 월드 사이트. 정적 파일만 있어서 `index.html`을 열면 동작한다.

## 구성

| 화면 | 주소 | 내용 |
|---|---|---|
| 메인 | `#/main` | 캐릭터 캐러셀, 좌측 텍스트·아이콘 메뉴, 우측 상단 메뉴 아이콘 |
| 캐릭터 선택 | `#/select` | 세로 카드 선택 창 |
| 캐릭터 소개 | `#/char/1` ~ | 이름·소개문·이전/다음 이동 |
| 컨셉아트 | `#/gallery` | 15장, 작은 그림 2장 + 큰 그림 1장 반복, 스크롤 |
| 공지 | `#/notice` | 패치 노트 |

화면이 바뀔 때마다 전환 애니메이션이 재생되고, 모바일(360px~)도 지원한다.

## 내용 바꾸기

`data.js` 한 파일만 고치면 된다.

- **캐릭터 그림**: `CHARS[].img`에 경로를 넣는다. 예: `img: "img/char-01.webp"`
- **컨셉아트 그림**: `CONCEPTS[].img`에 경로를 넣는다.
- **이름·소개문**: `CHARS[]`의 `ko`, `en`, `role`, `lines`
- **공지**: `PATCHES`에 새 항목을 맨 위에 추가한다.

`img`가 비어 있으면 `art.js`가 만든 임시 일러스트가 표시된다.
